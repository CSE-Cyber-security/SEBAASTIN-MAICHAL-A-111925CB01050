# Python Calculator

A simple command-line calculator written in Python. It supports addition, subtraction, multiplication, division, remainder, and exponentiation.

## Requirements

- Python 3.8 or later
- No external libraries required

## Run the project

1. Download or clone this repository.
2. Open a terminal in the project folder.
3. Run:

   ```bash
   python calculator.py
   ```

   On some systems, use `python3 calculator.py`.

## Supported operations

| Operator | Operation |
|---|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Remainder |
| `**` | Exponentiation |

The calculator handles invalid numeric input and prevents division or remainder by zero. Enter `q` at the first-number prompt to exit.

## Example

```text
Enter first number: 12
Enter operator (+, -, *, /, %, **): *
Enter second number: 3
Result: 36
```
