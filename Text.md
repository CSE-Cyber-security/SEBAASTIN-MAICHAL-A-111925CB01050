Fibonacci Series in C
Aim
To generate a Fibonacci series using C programming.

Description
The Fibonacci series is a sequence in which each number is the sum of the previous two numbers.

The series starts with 0 and 1.

Example
Input: 7

Output: 0 1 1 2 3 5 8

Files
code.c: C source code
data: Stores the generated Fibonacci series
text.md: Project documentation
How to Run
gcc code.c -o fibonacci ./fibonacci
